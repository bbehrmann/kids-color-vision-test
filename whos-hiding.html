Who's Hiding?

Turn photos of familiar people into dotted color-vision plates. The face is drawn only with color differences, so a child points to who they see instead of reading a number.

How to run the test
  1. Make a Practice (everyone sees) plate first. Use it to show the child the game: "Someone is hiding in the dots. Who is it?"
  2. Make deuteranopia, protanopia and tritanopia plates from different photos, so the child can't remember a face from an earlier plate.
  3. Tap a plate to show it full screen. Use a bright screen in normal room light, with night mode and blue-light filters off.
  4. If the child names the practice faces but not the others, check how the mask preview looks, then talk to a pediatrician or eye doctor.

This is a screening game for home use, not a medical test. Screens show color differently, so a missed plate means "get it checked," not a diagnosis.
